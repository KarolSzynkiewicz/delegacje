## Dokumentacja Projektu

Ten folder zawiera dokumentację techniczną i planowanie projektu.

- **PLAN.md** - Plan rozwoju projektu, roadmapa funkcjonalności
- **NOTIFICATIONS.md** - Powiadomienia w aplikacji (dzwonek): typy zdarzeń, @wzmianki w komentarzach i podzadaniach, jak dodać nowy typ
- **MCP-TASKS.md** - Serwer MCP `/mcp/tasks` (OAuth, narzędzia, kalendarz Planu, HITL)
- **GEMINI.md** - Notatki i dokumentacja dla AI (ignorowane w git)
